WRC Haven Resort Booking and Management System

Project Description

The WRC Haven Resort Booking and Management System is a web-based application designed to manage resort room reservations and administrative activities.

The system allows customers to submit room bookings while administrators can view, manage, update, and delete booking records.

Technologies Used

- PHP
- MySQL
- HTML
- CSS
- XAMPP
- phpMyAdmin
- GitHub

System Features

- Customer room booking
- Room type selection
- Check-in and check-out date selection
- Customer booking information management
- Administrator login
- Admin dashboard
- Booking editing and deletion
- Booking status management
- Payment processing simulation
- Receipt generation

Database

The application uses a MySQL database named "wrc_resort".

The database contains the following tables:

- "bookings"
- "rooms"

Installation Instructions

1. Install XAMPP.

2. Copy the project folder into the XAMPP "htdocs" directory.

3. Start Apache and MySQL.

4. Open phpMyAdmin.

5. Create a database named "wrc_resort".

6. Import the provided SQL database file.

7. Open the application in your browser:
   
   "http://localhost/wrc-resort-booking/"

Project Purpose

This project demonstrates the application of software engineering principles in the design and development of a resort booking and management system.
