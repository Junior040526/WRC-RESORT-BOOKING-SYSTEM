# WRC Haven Resort Booking System
## Software Test Plan

### 1. Introduction
The purpose of this test plan is to verify that the WRC Haven Resort Booking and Management System operates correctly, securely, and reliably.

### 2. Testing Objectives
- Verify that visitors can make bookings.
- Verify that room availability is checked.
- Verify that booking prices are calculated correctly.
- Verify that administrators can manage bookings.
- Verify that simulated payments are recorded.
- Verify that unauthorized users cannot access protected pages.

### 3. Testing Types

#### Unit Testing
Individual components such as database connections,
price calculations, and input validation.

#### Functional Testing
Complete booking, login, payment, editing,
deleting, and status update processes.

#### Non-Functional Testing
Usability, security, performance, and reliability.

### 4. Test Environment
- Operating System: Windows
- Web Server: Apache (XAMPP)
- Programming Language: PHP
- Database: MySQL
- Database Management: phpMyAdmin
- Browser: Google Chrome

### 5. Test Results
Test results will be recorded after executing
each test case on the running prototype.
